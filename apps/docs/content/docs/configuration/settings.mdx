# Settings

Every preference lives on one page. Open it with `Cmd+,` (macOS) / `Ctrl+,` (Windows/Linux), from **Settings** at the bottom of the sidebar, or from the command palette (`Cmd/Ctrl+K`). The page has six sections, listed on its left.

## General

- **Appearance.** Light, dark, or match the system.
- **Collapse the editor for table previews.** Opening a table shows its rows first, with the editor one click away. Default off.
- **Hide the quick query panel.** Keeps the sidebar to schemas and saved items. Default off.
- **Query timeout.** Cancel queries that run longer than this many seconds. Leave empty for no limit. Default no limit.
- **Expand JSON cells** and **JSON expansion depth.** How JSON values open in results. Default collapsed, depth 2.
- **Pokemon buddy.** An optional companion in the sidebar.

**Reset to defaults** at the bottom of General restores these values.

You can cancel a running query with the **Cancel** button that appears while it runs. This works for PostgreSQL, MySQL, SQL Server, and ClickHouse.

## AI

The top of the section shows which AI is in use and lets you pick its model. Below it, providers are grouped by how you pay:

- **Your subscription.** Claude Code, Codex, and Antigravity run through the CLI you already pay for and are signed in to. data-peek checks whether each is installed. Click **Use** to switch to it. No key needed.
- **API key.** OpenAI, Anthropic, Google, Groq, DeepSeek, Mistral, xAI, and GLM. Click **Add key**, paste it, optionally **Test** it, and **Save**. Saving your first key also makes that provider active. After that, **Use** switches between saved providers.
- **Local.** Ollama. Set its URL and click **Use**.

Keys stay on your machine, and requests go straight to the provider. See [AI Assistant](/docs/features/ai-assistant) for what the AI can do.

## Integrations

The [MCP server](/docs/features/mcp-server) lets local AI agents query your connections. Turn it on, set its port, and copy the command to register it with your agent.

## History & privacy

Time Machine keeps a history of your query runs, which you can turn off or wipe. The audit log records what ran against your databases, with retention, an integrity check, and export.

## Shortcuts

Every keyboard shortcut, grouped by where it applies.

## License

Your license status. Activate a commercial license or manage an existing one.

## Settings Storage

Settings are stored locally on your device:

- **macOS**: `~/Library/Application Support/data-peek/`
- **Windows**: `%APPDATA%\data-peek\`
- **Linux**: `~/.config/data-peek/`
