# Keyboard Shortcuts

data-peek is designed for keyboard-first navigation. Nearly every action in the editor, grid, sidebar, and tab bar can be driven from the keyboard.

---

## Global & Navigation

These shortcuts work from anywhere in the application.

| Action | macOS | Windows/Linux |
| :--- | :--- | :--- |
| **Command Palette** | `Cmd+K` | `Ctrl+K` |
| **Connection Switcher** | `Cmd+P` | `Ctrl+P` |
| **Toggle AI Assistant** | `Cmd+I` | `Ctrl+I` |
| **Toggle Sidebar** | `Cmd+B` | `Ctrl+B` |
| **Focus Sidebar Omnibar** | `/` | `/` |
| **Open Saved Queries** | `Cmd+Shift+S` | `Ctrl+Shift+S` |
| **Open Settings** | `Cmd+,` | `Ctrl+,` |
| **Toggle DevTools** | `F12` | `F12` |
| **Zoom In** | `Cmd++` | `Ctrl++` |
| **Zoom Out** | `Cmd+-` | `Ctrl+-` |
| **Reset Zoom** | `Cmd+0` | `Ctrl+0` |
| **Toggle Fullscreen** | `Cmd+Ctrl+F` | `F11` |

<Callout type="info">
  Pressing `/` focuses the sidebar omnibar when you are not currently editing text inside an input or the SQL editor.
</Callout>

## Results, Filtering & Sorting

Shortcuts for navigating results and filtering or sorting table data.

| Action | macOS | Windows/Linux |
| :--- | :--- | :--- |
| **Focus Smart Filter Bar** | `Cmd+F` | `Ctrl+F` |
| **Open Smart Sort Bar** | `Cmd+Shift+S` | `Ctrl+Shift+S` |
| **Move Between Cells** | `↑` `↓` `←` `→` | `↑` `↓` `←` `→` |
| **First / Last Cell in Row** | `Home` / `End` | `Home` / `End` |
| **First / Last Cell Overall** | `Cmd+Home` / `Cmd+End` | `Ctrl+Home` / `Ctrl+End` |
| **Jump 20 Rows** | `PageUp` / `PageDown` | `PageUp` / `PageDown` |
| **Copy Focused Cell** | `Cmd+C` | `Ctrl+C` |
| **Open Cell Inspector** | `Enter` | `Enter` |
| **Close Cell Inspector** | `Escape` | `Escape` |
| **Navigate Foreign Key** | `Cmd+Click` | `Ctrl+Click` |

<Callout type="info">
  - **`Cmd/Ctrl+F` context**: When the SQL editor has focus, `Cmd/Ctrl+F` opens editor search. When results or table previews are focused, `Cmd/Ctrl+F` focuses the Smart Filter bar.
  - **`Cmd/Ctrl+Shift+S` accelerator overlap**: `Cmd/Ctrl+Shift+S` is bound to opening the Smart Sort bar when a sort bar is visible on the active table tab. Note that this shortcut currently overlaps with the global Saved Queries menu accelerator.
</Callout>
