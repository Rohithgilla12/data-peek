# Keyboard Shortcuts

data-peek is designed for keyboard-first navigation. Nearly every action in the editor, grid, sidebar, and tab bar can be driven from the keyboard.

---

## Global & Navigation

These shortcuts work from anywhere in the application.

| Action | macOS | Windows/Linux |
| :--- | :--- | :--- |
| **Command Palette** | `Cmd+K` | `Ctrl+K` |
| **Connection Switcher** | `Cmd+P` | `Ctrl+P` |
| **Switch Connection 1–9** | `Cmd+Shift+1` to `Cmd+Shift+9` | `Ctrl+Shift+1` to `Ctrl+Shift+9` |
| **Toggle AI Assistant** | `Cmd+I` | `Ctrl+I` |
| **Toggle Sidebar** | `Cmd+B` | `Ctrl+B` |
| **Focus Sidebar Omnibar** | `/` | `/` |
| **Open Saved Queries** | `Cmd+Shift+S` | `Ctrl+Shift+S` |
| **Open Settings** | `Cmd+,` | `Ctrl+,` |
| **Toggle DevTools** | `F12` | `F12` |
| **Zoom In** | `Cmd++` | `Ctrl++` |
| **Zoom Out** | `Cmd+-` | `Ctrl+-` |
| **Reset Zoom** | `Cmd+0` | `Ctrl+0` |
| **Toggle Fullscreen** | `Cmd+Ctrl+F` | `F11` |

<Callout type="info">
  Pressing `/` focuses the sidebar omnibar when you are not currently editing text inside an input, textarea, contenteditable element, or the SQL editor.
</Callout>

### Find in Results

| Action | macOS | Windows/Linux |
| :--- | :--- | :--- |
| **Open Find** (focus in the grid) | `Cmd+F` | `Ctrl+F` |
| **Next / Previous Match** | `Enter` / `Shift+Enter` | `Enter` / `Shift+Enter` |
| **Next / Previous Match** (anywhere in the grid) | `Cmd+G` / `Cmd+Shift+G` | `Ctrl+G` / `Ctrl+Shift+G` |
| **Toggle Match Case** | `Option+C` | `Alt+C` |
| **Toggle Regular Expression** | `Option+R` | `Alt+R` |
| **Close Find** | `Escape` | `Escape` |

<Callout type="info">
  - **`Cmd/Ctrl+F` focus conditions**: When the SQL editor has focus, `Cmd/Ctrl+F` opens editor search. When focus is inside the results grid, it opens Find in Results. Everywhere else (sidebar, filter and sort bars, other non-editor areas), it focuses the mounted Smart Filter bar.
  - **`Cmd/Ctrl+Click`**: On a foreign-key value it opens the referenced record in a new tab. On any other cell it adds that cell to the selection, or removes it.
  - **`Cmd/Ctrl+Shift+S` focus & menu overlap**: When focus is outside the SQL editor and unrelated input, textarea, or contenteditable elements, `Cmd/Ctrl+Shift+S` activates the Smart Sort bar on tabs where sorting is available. Note that this shortcut currently overlaps with the application menu accelerator for Saved Queries.
</Callout>

## Tips

- Press `Cmd+K` / `Ctrl+K` to open the Command Palette to switch connections and open tabs, saved queries, and settings.
- Global and connection shortcuts work from anywhere in the window regardless of which panel currently has focus.
- Editor-specific shortcuts (execution, formatting, find) require active cursor focus inside the SQL editor.
